# GitHub introduction

## Aqua Nook 3D

Aqua Nook 3D is a live Windows desktop aquarium designed to feel like part of the desktop instead of a window placed on top of it. The native host attaches to the desktop WorkerW layer, so icons, taskbar, drag-and-drop and other windows continue to work normally.

The bundled WebGL scene provides six fish species, click-to-feed reactions, reef and river scenes, a mini bay, animated lighting, shadows, water scattering and suspended particles. The project ships with local assets and a compiled Windows build, so it runs without a web server, CDN, Python or Node runtime.

The project takes desktop wallpaper integration cues from [Lively Wallpaper](https://github.com/rocksdanister/lively) and scene foundations from [Deskworlds](https://github.com/chaseleantj/deskworlds). It is an independent Apache-2.0 project with third-party notices preserved in the repository.

## Giới thiệu tiếng Việt

Aqua Nook 3D là bể cá sống cho desktop Windows, được đặt dưới lớp icon thay vì phủ lên trên các cửa sổ. Host native gắn vào lớp WorkerW của desktop để icon, taskbar, kéo thả và các cửa sổ khác vẫn hoạt động bình thường.

Scene WebGL đi kèm có sáu loài cá, phản ứng khi thả thức ăn, cảnh rạn san hô và dòng suối, ánh sáng động, bóng đổ, tán xạ nước và hạt lơ lửng. Gói có sẵn asset cục bộ và bản build Windows, không cần web server, CDN, Python hoặc Node để chạy.

Dự án tham khảo cách tích hợp desktop của [Lively Wallpaper](https://github.com/rocksdanister/lively) và nền scene từ [Deskworlds](https://github.com/chaseleantj/deskworlds). Đây là dự án độc lập theo Apache-2.0, giữ nguyên thông báo các thành phần bên thứ ba.

Khi chạy nền, người dùng có thể chọn chất lượng thấp hơn hoặc tạm dừng. Tạm dừng dừng mô phỏng và render nhưng vẫn giữ asset đã tải trong bộ nhớ; thoát ứng dụng sẽ giải phóng tài nguyên tiến trình.
