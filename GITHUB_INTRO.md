# GitHub introduction

## Aqua Nook 3D

Aqua Nook 3D is a live Windows desktop aquarium designed to feel like part of the desktop instead of a window placed on top of it. The native host attaches to the desktop WorkerW layer, so icons, taskbar, drag-and-drop and other windows continue to work normally.

The bundled WebGL scene provides six fish species, click-to-feed reactions, reef and river scenes, a mini bay, sun-wheel detail, animated lighting, shadows, water scattering and suspended particles. The project ships with local assets and a compiled Windows build, so it runs without a web server, CDN, Python or Node runtime.

The project takes desktop wallpaper integration cues from [Lively Wallpaper](https://github.com/rocksdanister/lively) and scene foundations from [Deskworlds](https://github.com/chaseleantj/deskworlds). It is an independent Apache-2.0 project with third-party notices preserved in the repository.
